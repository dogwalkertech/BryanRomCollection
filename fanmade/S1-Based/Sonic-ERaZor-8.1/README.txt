Sonic ERaZor 8 - Widescreen Edition
===================================

-----------------------------------
=== WARNING ===

This is a special 16:9 version of this ROM hack exclusively and specifically optimized for the
	"Genesis Plus GX Wide"
	core available for RetroArch
and it will be super awkward if played on any other emulator!

Visit this URL to download the regular 4:3 version, compatible with any emulator and even real hardware:
https://selbi.hapisan.com/erazor

-----------------------------------
=== SETUP ===

1. Open RetroArch and go to "Load Core" -> "Download a Core".
2. Search for and install "Genesis Plus GX Wide".
3. Load the ROM!

For the best experience, disable sprite limits:
1. Load the ROM using the Wide core.
2. Press F1 to access Quick Settings.
3. Navigate to "Core Settings" -> "Emulation Hacks".
4. Turn ON "Remove Per-Line Sprite Limit".
